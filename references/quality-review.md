# 分层质量审查

## 审查原则

审查目标是发现作品可能失败、误导或无法执行的地方。每条问题必须有场景编号、证据或时间点、处理动作和复核结果。

区分两类结论：

- **客观问题**：依据输入、时间、配置、许可或媒体规格可以复现；可影响推进。
- **内容建议**：事实解释、措辞、叙事和审美判断；只供用户决定，不设置技术阻断。用户决定后准确执行，不重复争论。

客观问题级别：

- `阻断`：文件不可用、核心输入漂移、事实复制错误、时间轴非法或无法完成交付；
- `高`：高概率误读、关键文字遮挡、数字口径缺失、严重安全区或同步错误；
- `中`：理解变慢、节奏不稳、轻微风格漂移或局部换行问题；
- `低`：不影响理解与交付的细节优化。

## 脚本级 QA

从以下视角检查：

1. **事实与文字**：名称、数字、单位、范围和限定条件是否与权威输入一致。
2. **恶意误读**：标题、箭头、颜色和符号是否暗示不存在的因果或承诺。
3. **普通观众**：短时间内能否说出唯一结论，是否同时竞争多组信息。
4. **移动端**：最小文字、人物、字幕和平台遮挡是否可共存。
5. **动画执行**：时间、顺序、停留、转场和退场是否可实现。
6. **后期集成**：场景边界、命名、音轨、输出和相邻交接是否明确。

存在开放的客观 `阻断` 或 `高` 问题时，不进入批量实现。内容建议等待用户决定，但不得被伪装成客观故障。

## 渲染级 QA

每场至少检查入场建立后、信息最完整时和交接前；复杂动画增加转折点。

- 逐字核对文字、数字、符号和字幕引用。
- 检查闪现、裁切、重叠、越界、异常停留和退场残帧。
- 检查入场顺序是否符合认知顺序。
- 检查人物、字幕、主要动画和平台控件是否互相遮挡。
- 检查颜色、字体、字号、圆角、图标和动效语言的一致性。
- 检查文件数量、时长、分辨率、帧率、编码、音频、字幕和可解码性。

## 报告要求

报告汇总各级客观问题数量、内容建议数量、是否允许继续，以及仍需用户决定的事项。通过时保持简短；失败时给出可执行的场景和时间定位。
