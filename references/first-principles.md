# 第一性原理动效拆解

## 目标

动效的价值是降低理解成本、明确边界并建立记忆锚点。先判断观众的认知任务，再决定是否需要画面以及使用什么结构。

## 五问模型

对每个真实时间区间依次回答：

1. 观众此刻必须新增什么理解？
2. 信息难在数字抽象、关系复杂、概念易混、步骤过多，还是边界容易遗漏？
3. 画面是否比真人口播或字幕更快、更准确？
4. 删除装饰后，完成理解所需的最少元素是什么？
5. 观众只记住一句话或一个画面时，应该是什么？

第 3 问答案为否时，不制作额外动画。

## 信息结构映射

| 信息本质 | 优先结构 | 避免 |
|---|---|---|
| 单个数字 | 数字计数、比例尺、进度环 | 无意义粒子 |
| 两项比较 | 并排卡片、同轴条形、差异高亮 | 两套无关画风 |
| 多项比较 | 表格、矩阵、分组列表 | 逐句字幕堆叠 |
| 操作步骤 | 路径、时间线、流程节点 | 无方向图标 |
| 条件分支 | 决策树、闸门、分流路径 | 单线流程误导 |
| 责任或适用边界 | 容器、范围、内外区间 | 模糊渐变 |
| 算例 | 分步算式、金额流向 | 只给最终结果 |
| 分类 | 宫格、标签组、层级卡片 | 长段文字 |
| 误区纠正 | 错误命题→否定→正确命题 | 只打红叉 |
| 行动建议 | 检查表、决策清单 | 宣传口号 |

## 最小充分原则

- 一个场景只承担一个主认知任务。
- 每个状态最多一个主结论、一个辅助解释和一个主要视觉动作。
- 数字带单位；比例写明基数或适用范围。
- 对比使用相同维度、口径和时间范围。
- 流程具有方向，分支写明条件。
- 算例明确区分演示与真实承诺。
- 限定词、否定词和责任边界不能在压缩文案时丢失。

## 候选判断

按 0–2 分评估理解增益、记忆增益、信息密度、误读风险和制作价值：

- 7–10：优先动画化；
- 4–6：合并、简化或使用轻提示；
- 0–3：保留真人口播。

评分只辅助判断，不要求为每个场景机械生成多个完整方案。

## 屏幕文字压缩

先写完整事实，再依次删除口头连接词、重复主语和可由结构表达的关系。保留所有会改变结论的条件、单位、范围、否定和例外。
